# ロードマップ

各段階は前提条件と受け入れ条件を満たしてから次へ進む。ユーザーのレビューが必要な仕様判断は独断で決めない。

## Phase 0 — 実現性・権利調査

- 現行macOSの公開IME API、配布要件、Apple Silicon構成を一次資料で調査。
- Mozc等の変換エンジン候補を比較。オフライン、絵文字・英単語排除、順位制御、辞書ライセンス、保守状況を確認。
- Mac標準IMEのモード、候補、文節、取消・確定の操作を実測して入力キー表を作成。
- 標準IMEユーザー辞書のエクスポートとフォーマットを確認。
- 最小macOSバージョンと配布方式の案を提示する。最小対応の目標はmacOS 26.0で利用者確認済み。

**現状**。一次資料、SDK、標準IMEの主要キー操作、架空語1件のplist、Mozc CLIでの変換・文節伸縮を確認済み。複数件の辞書形式、組み込み時の候補除外、辞書と依存の配布条件は次の検証項目。

**完了条件**。技術判断ログ、依存ライセンス表、実測済みのキー表、辞書サンプルの検証結果が揃い、採用する構成に重大な権利・実現性ブロッカーがない。Phase 1への移行は範囲の承認後とする。

## Phase 1 — IME骨格・決定的入力

- macOSへの登録、Apple Siliconでの起動、ローマ字入力と日本語/英字モード。
- 未確定入力、確定、取消、変換要求の状態管理。変換エンジンの出力と候補UIを伴う確認はPhase 2で行う。
- 入力中の候補なし、ライブ・予測変換なし、通信なしを担保。

**現状**。入力処理とarm64バンドルは実装済み。macOS 26.5.2で実行ファイルが署名評価に通らず、登録・入力ソース切替の確認には公証済みビルドが必要。登録に依存しない機能を並行して開発する。

**完了条件**。テスト仕様のPhase 1の入力・モード・オフライン必須項目を満たす。

## Phase 2 — 変換と候補

- ローカル変換エンジン、文節および全体変換。
- 絵文字・英単語候補の排除、安定順位、`Ctrl+K` カタカナ変換。ユーザー辞書の最上位規則はこの段階でテスト用データを使って検証できる。ユーザー向け管理・インポートはPhase 3。
- 標準IMEを参考にした候補操作と候補UI。

**現状**。Mozc付き検証ビルドで変換・文節伸縮・順位再現を確認済み。候補の除外と操作は状態機械をテスト済み。InputMethodKitの候補パネルを使う実機確認が残る。

**完了条件**。候補除外、候補順位再現、変換・文節・カタカナ項目を満たし、複数アプリで動く。

## Phase 3 — 辞書・設定

- ローカルユーザー辞書の登録、編集、削除。
- Mac標準IME辞書インポート。
- macOS標準風設定画面、ライト・ダーク対応。
- 必要と確定した範囲のキー割当。

**現状**。ユーザ辞書の登録・編集・削除、ローカル保存、Appleのplistのインポート、変換時の最上位表示を実装済み。設定画面とインポートの操作・外観は、入力ソース登録後に実機で確認する。

**完了条件**。辞書、設定、外観、インポート失敗処理の項目を満たす。

## Phase 4 — 利用者評価・互換性

- 日常利用の変換精度、安定性、キー衝突、アクセシビリティ、スリープ復帰、複数アプリを評価。
- 指摘を分類し、仕様変更の承認後に改善。対応対象にした最小OSと各OS世代で、導入から削除まで検証する。

**未解決の課題（2026-11-27 時点）**

- カーソル下の入力モード表示（macOSの青い丸）が空のまま。`TISIconLabels`（あ / A）を追加し、入力ソースのキャッシュに反映されたことは確認した。表示用プロセス（CursorUIViewService、TextInputSwitcher）を再起動しても変わらない。利用者がログアウト・ログイン後に再確認する予定。

**完了条件:** 利用者が主要な不満を確認し、重大な不具合がなく、既知制限が文書化される。

## Phase 5 — OSS公開準備（公開判断は別）

- 依存・辞書・配布物のライセンス/NOTICE、第三者ビルド、導入/削除手順、署名・公証要否を確認。
- README、変更履歴、サポート対象、既知制限、プライバシー説明を整える。
- GitHub公開と一般配布は利用者の明示的な判断を待つ。
