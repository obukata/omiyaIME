# 入力仕様

「確定」はヒアリングで合意された要件、「仮説・要確認」は追加の検証や利用者判断を要する内容。初回の入力検証は利用者が使う英字配列（US/ANSI）を基準とする。

## モード・文字

| 状態 / キー | 仕様 | 状態 |
|---|---|---|
| 日本語モード | ローマ字でかなを入力。表示・出力は全角。ただし、かなにならなかった英字と数字は半角（2026-11-27 利用者回答）。 | 確定 |
| 英字モード | 半角英字等を入力。 | 確定 |
| モード切替 | Mac標準IMEと同じ操作を目指す。正確なキー・イベント仕様は調査する。 | 目標確定、詳細要確認 |
| 数字 | 日本語モードの未確定文字では半角（2026-11-27 利用者回答で全角から変更）。英字モードは半角。テンキーなどのキー別対応は要確認。 | 確定 |
| 記号 | 日本語モードは全角、英字モードは半角。日本語モードでは必要な句読点として `,` → `、`、`.` → `。` を確定。その他の配列は要確認。 | 基本方針確定 |
| Space（未確定文字なし） | 日本語モードでは全角空白、英字モードでは半角空白。 | 初期版で採用 |
| Space（未確定文字あり） | 標準IME相当の変換操作を目指す。 | 目標確定、詳細要確認 |

初期版は固定キーとする。日本語モードの数字は半角（2026-11-27 利用者回答）。Phase 1ではUS/ANSIのASCII記号を対応する全角文字にし、コンマとピリオドは「、」「。」、ハイフンは長音「ー」、`[` `]` は「「」「」」とする（2026-11-27 利用者報告）。配列・修飾キー・テンキーの実機互換性は検証する。

## かな入力・変換

1. ローマ字入力からひらがなの未確定文字列を構成する。
2. 変換を要求されるまでは変換候補を表示しない。ライブ変換・予測変換・入力中サジェストをしない。
3. 通常の変換操作で漢字・かな等の候補を提示する。候補は絵文字および英単語を含まない。
4. 文節単位の変換と文章全体の変換を使えるようにする。分節・伸縮・移動キーは標準IMEの挙動を調べて確定する。
5. 候補順位は学習で変わらず、同じ条件で安定させる。ユーザー辞書語は最上位。
6. 句読点を入力しても自動変換・確定しない。文字を入力するだけとする。
7. Enter等による確定、Escape等による取り消しは標準IME相当を目指し、キー詳細は調査後にテスト可能な表にする。

## カタカナ

- `Ctrl+K` をカタカナ変換操作として提供する。
- 読みをカタカナ化し、未確定状態を維持する。Enterで確定する。
- 変換中に選択された文字列だけを対象とするか、未変換文字列全体も対象とするかは標準IME挙動を調べて決める。
- 候補順位におけるカタカナと漢字の一般的な優先ルールは未決。通常変換は一貫性を重視し、ユーザー確認なしに「漢字常に先頭」等を導入しない。

## 辞書

- ローカルユーザー辞書の登録・編集・削除を提供する。
- ユーザー辞書にある一致語は通常候補の最上位に出す。
- Mac標準IME辞書をインポートする。Apple公式の書き出しplistを入口とする。26.5.2のUTF-8 XMLでは、配列の各項目の `shortcut` が読み、`phrase` が変換先の文字列。複数件と他の対象OSでの互換範囲は要検証。重複・競合・不正行や、絵文字・英単語除外と衝突する辞書語の扱いは未決。
- クラウド同期は要件外。辞書はローカルに保存し、通信しない。

## 実装前に作成するキー表

[Phase 0のキー表](ARCHITECTURE.md#apple標準imeの操作と実測項目)に公式資料で確認した操作と実測項目を記録した。採用するOS APIと標準IME実測に基づき、押下キー、モード、未確定状態、期待文字または動作、確定状態を網羅した表を作る。少なくともモード切替、文字入力、Space、Return、Escape、矢印、候補選択、文節移動、`Ctrl+K`、句読点を含める。標準IMEの不明な挙動は推測で互換と宣言しない。

## Phase 1のキー表

| モード・状態 | キー | 動作 |
|---|---|---|
| 日本語・ローマ字入力中 | A–Z | ローマ字をかなに変換して未確定表示。大文字のキー入力も同じ読みになる。 |
| 日本語・入力中または空 | 数字、記号 | 数字は半角、記号は全角の未確定文字を追加。コンマ、ピリオド、ハイフンは「、」「。」「ー」。かなにならなかった英字も半角で表示・確定する。 |
| 日本語・入力中 | Ctrl+K | 現在の読みを全角カタカナで未確定表示。カタカナ表示はこの未確定入力が終了するまで維持。 |
| 日本語・入力中 | Space | 変換要求を受理し、読みを未確定のまま維持。候補表示はPhase 2。 |
| 日本語・入力中 | Return / Enter / Shift+Return | 未確定文字を確定（改行はしない）。Shift+Returnもアプリへ渡さず確定にする。アプリ側で改行扱いされ未確定文字が消えるのを防ぐため（2026-11-27 実機報告）。 |
| 日本語・入力中 | Escape / Delete | Escapeは入力全体を取消。Deleteは表示上の最後の1文字を削除（「nn」による「ん」は一度に消す）。削除の結果、かなにならなかった英字が末尾に残れば、ローマ字入力の途中として扱い直し、続けて打った母音などと合わせてかなにする（例: t → e で「て」。2026-11-27 利用者報告）。 |
| 日本語・空 | Space | 全角空白を直接入力。 |
| 日本語・入力中または空 | Shift+英字 | 英字モードへ切り替え（入力メニューも英字に）、その英字を未確定で表示する。打ちかけのかな・変換中の文字は先に確定する（2026-11-27 利用者回答。標準IME準拠）。 |
| 英字・Shift+英字で始めた未確定あり | 英字、数字、記号 | 未確定の英字に追加。Deleteで1文字削除、Escapeで取り消し。 |
| 英字・Shift+英字で始めた未確定あり | Return / Space | Returnは確定のみ。Spaceは確定して半角空白を入力。そのほかのキー（矢印など）は確定してからアプリに渡す。確定後も英字モードのまま。 |
| 日本語 | z+h / z+j / z+k / z+l | ← / ↓ / ↑ / → を入力（2026-11-27 利用者回答。標準IME準拠）。 |
| 英字 | 文字、数字、記号、Space | キーをホストへ渡す。US配列では半角で入力。 |
| 日本語／英字 | JISの「かな」／「英数」 | 「かな」で日本語、「英数」で英字に切り替える。未確定の入力（変換中を含む）は標準IMEと同じく確定してから切り替える（2026-11-26 利用者の実機報告を受けて追加）。 |
| 日本語／英字 | macOSの入力メニュー | モードを選択。モード変更時に確定されていない入力は取り消す。Ctrl+Shift+J / Ctrl+Shift+; もバンドルに登録し、キーでの切替は実機で確認する。 |

変換中の操作を除き、矢印などの編集キーやアプリのショートカットはホストへ渡す。入力先から未確定入力の確定を要求された場合、その時点の文字を確定する。

## Mozc付き開発版の変換操作

| キー | 動作 |
|---|---|
| Space | 1回目で入力全体を変換して下線付きで表示。2回目で現在の文節の候補一覧を開き、以降の押下で次の候補を選ぶ。 |
| 上下 / Shift+Space | 上下で前後の候補を選ぶ。Shift+Spaceは前の候補を選ぶ。 |
| 左右 / Shift+左右 | 左右で文節移動。Shift+左で短縮、Shift+右で伸長。 |
| Return / Shift+Return | 選択している候補で文章全体を確定。 |
| Escape | 変換結果を取り消して未確定の読みに戻す。もう一度押すと読みに対する未確定入力も取り消す。 |

一覧を表示する前に、絵文字や英字だけの候補を除外する。変換器の候補順を保ち、ユーザ辞書の一致項目を先に表示する。
